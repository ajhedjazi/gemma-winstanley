# Gemma Website Rules (SAFE MODE)

## Core rule
Do not make global or design changes unless explicitly requested in a task file.

## Safety constraints
- Never redesign pages
- Never change layout structure
- Never refactor CSS or HTML unless asked
- Keep changes small and reversible

## Allowed changes
- SEO improvements
- Text clarity improvements
- Small spacing fixes if explicitly requested
- Accessibility improvements

## Behaviour rule for Codex
If unsure → do nothing or ask for clarification
