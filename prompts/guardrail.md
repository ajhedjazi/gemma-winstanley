# Personal Guardrail (IMPORTANT)

Before making any change, ask:

1. Will this meaningfully improve the site OR am I tweaking for perfection?
2. Is this reversible?
3. Is this a “real problem” or an “attention problem”?

If it’s minor aesthetic anxiety → do NOT change the site.
Park it.

Only act on changes that improve:
- clarity
- conversion
- SEO
- performance
